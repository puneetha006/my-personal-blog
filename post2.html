Designing and Developing a Personal Blogging Website

For my Computer Science & Engineering case study at T. John Institute of Technology, I designed, built, and deployed this responsive personal blogging and portfolio website from scratch.

What Went Into Building This Site

  • Semantic HTML5 Structure: Organized content cleanly using <header>, <section>, <article>, and <footer> tags.
  • Responsive CSS3 Grid & Flexbox: Designed a layout that adapts smoothly across mobile phones, tablets, and laptops.
  • Interactive Dark Mode: Added a JavaScript theme switcher that remembers the reader's light or dark preference using localStorage.
  • Cloud Hosting via GitHub Pages: Deployed the entire project online with continuous updates through GitHub.

Building this project showed me how combining simple front-end fundamentals with clean design can turn personal ideas into a live, accessible web application.

Built from scratch with HTML5, CSS3, and JavaScript.
