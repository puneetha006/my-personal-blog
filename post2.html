Designing and Developing a Personal Blogging Website

For my CSE case study at T. John Institute of Technology, I designed and built a responsive personal blogging and portfolio website from scratch using HTML5 and CSS3.

Key Technical Highlights

  • Semantic HTML5: Used clean tags like <header>, <section>, <article>, and <footer> for accessibility and SEO.
  • Responsive CSS Grid & Flexbox: Built a layout that adapts smoothly across laptops, tablets, and mobile phones.
  • Lightweight Performance: Zero heavy frameworks—resulting in instant page loads.

This project taught me how to balance clean visual design with maintainable front-end architecture.
